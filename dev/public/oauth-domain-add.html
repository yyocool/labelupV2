콘솔 등록 목록

서버에 www.labelup.co.kr / labelup.co.kr 을 연결했고, www.labelup.kr / labelup.kr 도 같은 앱으로 붙입니다. 콜백 URL은 접속한 도메인 그대로 만들어지므로, 사용자가 들어오는 주소마다 콘솔에 등록해야 합니다. 키(Client ID/Secret)는 새로 발급하지 말고 기존 앱에 URL만 추가하면 됩니다.

유지 · 개발 HTTP 추가 · 운영 4개 HTTPS
주소는 한 글자도 다르게 쓰면 로그인 실패합니다. http/https, www 유무, 끝의 / 여부를 그대로 맞추세요. 콜백 경로 고정값: /auth/naver/callback · /auth/kakao/callback · /auth/google/callback

5. 하지 않아도 되는 것

키 재발급

  • 네이버 Client ID / Secret
  • 카카오 REST API 키 / Secret
  • 구글 Client ID / Secret

서버 .env에 이미 들어 있습니다. URL만 추가하면 됩니다.

앱 코드 / 서버 설정

  • 콜백 경로는 이미 /auth/{제공자}/callback 입니다
  • 접속한 호스트를 그대로 쓰도록 서버는 반영되어 있습니다
  • 키를 바꾸지 않는 한 배포는 필요 없습니다
