LabelUp · OAuth Setup

네이버 · 카카오 · 구글
소셜 로그인 키 발급 안내

이 페이지는 키를 발급해 줄 담당자에게 그대로 전달하면 됩니다. 아래 순서대로 발급하고, 마지막의 전달 값 목록만 개발자에게 보내 주세요.

네이버

Client ID + Client Secret

카카오

REST API 키 (+ Client Secret 권장)

구글

Client ID + Client Secret

0. 공통으로 꼭 맞출 콜백 주소

네이버·카카오·구글 콘솔에 개발 / 운영 도메인 콜백 URL을 모두 등록해 주세요. 주소는 아래와 한 글자도 다르지 않게 입력해야 합니다. (http / https 구분 포함)

개발 개발 도메인

http://labelupdev.gagamkorea.kr

http://labelupdev.gagamkorea.kr/auth/naver/callback http://labelupdev.gagamkorea.kr/auth/kakao/callback http://labelupdev.gagamkorea.kr/auth/google/callback

운영 운영 도메인

https://www.labelup.co.kr

https://www.labelup.co.kr/auth/naver/callback https://www.labelup.co.kr/auth/kakao/callback https://www.labelup.co.kr/auth/google/callback
서비스 URL(사이트 주소)도 가능하면 두 도메인을 모두 등록하세요.
개발: http://labelupdev.gagamkorea.kr · 운영: https://www.labelup.co.kr

1) 네이버 로그인

developers.naver.com
1

네이버 개발자 센터 접속

애플리케이션 등록 페이지로 이동합니다. 네이버 계정 로그인이 필요합니다.

2

새 애플리케이션 등록

  • 애플리케이션 이름: 라벨업 (또는 회사 표기명)
  • 사용 API: 네아로(네이버 로그인) 선택
  • 비로그인 오픈API 서비스 환경: PC 웹
3

서비스 URL / Callback URL 입력

  • 서비스 URL에 개발·운영 둘 다 등록
    http://labelupdev.gagamkorea.kr https://www.labelup.co.kr
  • Callback URL에도 개발·운영 둘 다 등록
    http://labelupdev.gagamkorea.kr/auth/naver/callback https://www.labelup.co.kr/auth/naver/callback
4

제공 정보 선택

회원 이름, 이메일을 반드시 포함해 주세요. (이메일 없으면 자동 가입 품질이 떨어집니다)

5

발급 결과 확인

애플리케이션 상세에서 아래 2개 값을 복사합니다.

개발자에게 전달할 값 (네이버)

  • NAVER_CLIENT_ID = Client ID
  • NAVER_CLIENT_SECRET = Client Secret

2) 카카오 로그인

developers.kakao.com
1

카카오 개발자 콘솔 접속

내 애플리케이션에서 앱을 만들거나 기존 앱을 선택합니다.

2

앱 키 확인

앱 설정 → 앱 키 메뉴에서 REST API 키를 복사합니다. (JavaScript 키가 아닙니다)

3

카카오 로그인 활성화

  • 제품 설정 → 카카오 로그인 → 활성화 ON
  • Redirect URI에 개발·운영 둘 다 등록
    http://labelupdev.gagamkorea.kr/auth/kakao/callback https://www.labelup.co.kr/auth/kakao/callback
4

동의 항목 설정

  • 닉네임: 필수 또는 선택
  • 카카오계정(이메일): 가능한 한 필수로 설정
5

(권장) Client Secret 사용

보안 → Client Secret 생성/사용 설정 ON 후 Secret 코드를 복사합니다. 없어도 동작은 가능하지만 보안상 권장합니다.

개발자에게 전달할 값 (카카오)

  • KAKAO_REST_API_KEY = REST API 키
  • KAKAO_CLIENT_SECRET = Client Secret (사용 시)

3) 구글 로그인

console.cloud.google.com
1

Google Cloud 콘솔 접속

API 및 서비스 → 사용자 인증 정보로 이동합니다. 프로젝트가 없으면 먼저 생성합니다.

2

OAuth 동의 화면 설정

  • User Type: 외부(일반 서비스) 또는 내부(조직 전용)
  • 앱 이름: 라벨업
  • 지원 이메일 / 개발자 연락처 입력
  • 범위(Scopes): email, profile, openid
3

OAuth 클라이언트 ID 만들기

  • 만들기 → 애플리케이션 유형: 웹 애플리케이션
  • 승인된 자바스크립트 원본(선택)에 개발·운영 둘 다 등록
    http://labelupdev.gagamkorea.kr https://www.labelup.co.kr
  • 승인된 리디렉션 URI에 개발·운영 둘 다 등록
    http://labelupdev.gagamkorea.kr/auth/google/callback https://www.labelup.co.kr/auth/google/callback
4

발급 결과 확인

생성 직후 뜨는 팝업 또는 클라이언트 상세에서 Client ID / Client Secret을 복사합니다.

개발자에게 전달할 값 (구글)

  • GOOGLE_CLIENT_ID = 클라이언트 ID
  • GOOGLE_CLIENT_SECRET = 클라이언트 보안 비밀번호
