프로젝트 진행률 요약

검수표(1차 구축) 기준으로 현재 구현·준비 상태를 한눈에 정리한 요약본입니다. 세부 항목 검수는 검수표에서 별도 진행합니다.

기준일 2026.09.11 전체 체감 진행률 약 88~92%

1. 영역별 진행 현황

영역 진행률 현재 상태 · 잔여 작업
쇼핑몰 기능 완료
  • 기능적으로 완료. PG는 토스페이먼츠 기본 연동 준비.
  • 상품 상세페이지 제작: 차주 착수. 초기 2건 내용·디자인 컨펌 후 전체 작업 3~4일 소요 예정(대기).
편집기 ≈ 90%+
  • 기능적으로 90% 이상 완료.
  • 샘플 용지 출력 테스트 진행 예정.
데이터 지속 확장
  • 클립아트 1,190개 준비(9/11 현재) · 계속 업데이트.
  • 템플릿 410셋 준비(9/11 현재) · 계속 업데이트.
AI 기능 완료
  • 기능적으로 완료.
  • 오픈 후에도 프롬프트·모델·비용 정책 등 지속 업데이트 필요.
기타 연동 차주 초
  • 구독 요금 설정, 소셜 로그인 셋팅, PG 연동, 구매고객 크레딧 지급(QR 출력 포함).
  • 차주 초 완료 예정.

2. 기존 계획 대비 — 추가 반영된 항목

초기 개발범위에 없었거나, 운영 편의·오픈 준비로 보강된 기능입니다.

  • QR 쿠폰 랜딩 — 패키지 QR → 고유 쿠폰코드 발급·크레딧 지급 흐름
  • 호환코드 공개 조회 — `/compat`, `/compat-codes` 및 QR 샘플 페이지
  • 히어로 이미지 — 테마 교체 + 관리자 직접 업로드
  • 클립아트 확장 — 업무/물류 문구, 교통(고품질 재작업), 라비 마스코트 팩
  • 클립아트 배경 투명화 — HQ 자산 일괄 정리
  • 검수표 고도화 — 고객사 확인·검수 코멘트·상태 관리
  • 상세페이지 관리 — 상품별 미리보기·페이지 설정 이전
  • AI 크레딧/템플릿 팩 — 운영·시드 체계 보강

3. 한눈에 보는 잔여 일정

  • 이번 주~차주 — 편집기 샘플 출력 테스트
  • 차주 초 — 구독요금 / 소셜로그인 / PG / 크레딧·QR
  • 차주 — 상품 상세 초기 2건 컨펌 → 전체 상세 3~4일
  • 상시 — 클립아트·템플릿·AI 품질 업데이트

4. 오픈 관점 요약

  • 핵심 서비스(쇼핑몰·편집기·AI·콘텐츠)는 실사용 가능 수준.
  • 오픈 직전 병목은 상품 상세 콘텐츠와 결제·계정·크레딧 연동 마무리.
  • 데이터·AI는 오픈 후에도 지속 확장하는 운영형 자산.
