고객사 요청 사항

개발 연동은 완료되었습니다. 지금은 각 플랫폼이 개발/테스트 모드라서 등록된 계정만 로그인됩니다. 모든 회원이 네이버·카카오·구글로 가입/로그인하려면 아래 검수·게시를 고객사 담당자(콘솔 권한 보유자)가 진행해 주셔야 합니다.

1. 역할 구분

CUSTOMER

고객사에서 해 주실 일

  • 네이버·카카오·구글 개발자 콘솔 로그인 (앱 소유 계정)
  • 사업자·로고·약관 URL 등 검수 자료 준비
  • 각 플랫폼 검수 신청 / 프로덕션 게시
  • 검수 보완 요청이 오면 회신
  • 완료 후 상태(또는 운영용 키)를 개발사에 회신
DEVELOPER

개발사에서 이미 한 일 / 이어서 할 일

  • 로그인·회원가입 화면과 콜백 연동 완료
  • 개발 서버에 네이버·구글 키 적용 완료
  • 콜백 URL 안내 및 서버 반영
  • 검수 통과 후 운영 서버 .env 적용
  • 운영 도메인에서 실로그인 점검
지금 막히는 현상: 네이버 앱 labelup_dev가 개발 중 상태입니다. 개발 중에는 콘솔에 등록한 네이버 아이디만 로그인됩니다. 일반 회원 오픈은 검수 통과가 필요합니다.

2. 세 곳 공통으로 미리 준비할 자료

검수 화면에서 빠지면 반려되는 항목입니다. 운영 사이트(https://www.labelup.co.kr) 기준으로 준비해 주세요. 가능하면 https 주소만 사용합니다.

약관 URL은 지금 검수에 바로 쓸 수 없습니다. 내용은 관리자 운영설정에 있으나, 공개 주소는 /api/legal/privacy, /api/legal/terms처럼 JSON만 내려줍니다. 네이버·카카오·구글은 사람이 읽는 웹페이지를 요구하므로, 고객사에서 문구를 확정해 주시면 개발사가 https://www.labelup.co.kr/legal/privacy, https://www.labelup.co.kr/legal/terms 형태의 공개 HTML을 만들어 드리겠습니다. 이미 회사 홈페이지에 약관이 있으면 그 URL을 쓰셔도 됩니다.

3. 네이버 — 검수 통과 (서비스 적용)

developers.naver.com

현재: 개발 중 · 등록 아이디만 로그인
1

애플리케이션 확인

내 애플리케이션에서 labelup_dev를 엽니다. 운영 오픈용이면 앱 이름을 라벨업으로 바꾸거나, 운영 전용 앱을 새로 만드는 것을 권장합니다.

2

서비스 URL / Callback 재확인

  • 서비스 URL: https://www.labelup.co.kr (개발 도메인도 유지 가능)
  • Callback: https://www.labelup.co.kr/auth/naver/callback
  • 개발용: http://labelupdev.gagamkorea.kr/auth/naver/callback
3

제공 정보(동의항목)

회원이름, 이메일을 사용합니다. 이메일 미제공 시 자동 가입이 불완전해집니다. 사용 목적에는 아래를 적어 주세요.

회원 식별, 로그인, 주문·라벨 작업공간 연결

4

서비스 정보 입력

  • 서비스 로고, 카테고리, 서비스 소개
  • 개인정보 처리방침 URL, 이용약관 URL
  • 고객센터 연락처
5

검수 요청

애플리케이션 상세에서 검수 요청 / 서비스 적용을 제출합니다. 통과 전에는 테스트 계정만 됩니다. 검수에는 보통 수일~2주가 걸립니다.

6

검수 전까지 내부 테스트

멤버관리(또는 테스트 계정)에 담당자 네이버 아이디를 등록하면, 검수 전에도 그 계정으로는 로그인할 수 있습니다.

4. 카카오 — 비즈앱 + 동의항목 검수

developers.kakao.com

REST API 키 전달 후 버튼 활성화
1

앱 키 확인 (아직 미전달)

앱 설정 → 앱 키에서 REST API 키를 복사해 개발사에 보내 주세요. JavaScript 키가 아닙니다. Client Secret도 사용 중이면 함께 보내 주세요.

2

비즈 앱 전환

  • 앱 설정 → 비즈니스에서 사업자 정보 등록
  • 사업자등록번호로 카카오 비즈니스 채널/비즈앱 연결
  • 일반 앱 상태로는 실서비스 검수가 제한되는 경우가 많습니다
3

카카오 로그인 · Redirect URI

  • 제품 설정 → 카카오 로그인 → 활성화 ON
  • https://www.labelup.co.kr/auth/kakao/callback
  • http://labelupdev.gagamkorea.kr/auth/kakao/callback
4

동의 항목

  • 닉네임: 필수 또는 선택
  • 카카오계정(이메일): 필수 권장. 필수로 두면 검수 대상이 됩니다
  • 개인정보 처리방침 URL 등록
5

동의항목 검수 제출

카카오 로그인 → 동의 항목에서 검수 요청을 올립니다. 서비스 설명, 이메일이 필요한 이유, 실제 동작 화면(로그인 버튼·동의창) 캡처를 첨부하면 통과가 빠릅니다.

5. 구글 — OAuth 동의 화면 프로덕션 게시

console.cloud.google.com

테스트 모드면 테스트 사용자만 로그인
1

OAuth 동의 화면 열기

API 및 서비스 → OAuth 동의 화면. User Type은 외부입니다.

2

앱 정보 입력

  • 앱 이름: 라벨업
  • 사용자 지원 이메일, 개발자 연락처 이메일
  • 앱 로고 (권장)
  • 앱 도메인: labelup.co.kr
  • 홈페이지: https://www.labelup.co.kr
  • 개인정보처리방침 / 이용약관 URL (https)
3

범위(Scopes) 확인

현재 연동은 openid, email, profile만 사용합니다. 민감 범위가 아니라 브랜드 전체 검증 없이 프로덕션 게시가 가능합니다. 미인증 앱은 처음 로그인 시 경고가 뜰 수 있으나, 게시 후 일반 계정으로 진행됩니다.

4

리디렉션 URI 확인

  • https://www.labelup.co.kr/auth/google/callback
  • http://labelupdev.gagamkorea.kr/auth/google/callback
5

게시(Publish)

동의 화면 상태가 테스트이면 테스트 사용자만 됩니다. 프로덕션으로 게시를 눌러 게시 완료로 바꿉니다. 게시 전 내부 확인용으로만 쓰려면 테스트 사용자에 담당자 지메일을 추가하면 됩니다.

6. 검수 통과 후 개발사에 회신할 내용

키를 새로 발급하지 않았고 상태만 바뀌었다면, 아래 체크만 보내 주셔도 됩니다. 운영 전용 앱을 새로 만들었다면 Client ID/Secret을 다시 보내 주세요.

고객사 → 개발사 회신 템플릿
