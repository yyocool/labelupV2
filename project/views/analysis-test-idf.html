1. 파일 정체

바이너리 헤더에 Standard Jet DB 문자열이 있으며, Microsoft Access / Jet 4.0 계열 데이터베이스 컨테이너입니다. 내부에는 Access/VBA 메타데이터(VBA6, VBA7, Microsoft Access 14.0)와 라벨 설계용 테이블/필드명이 UTF-16LE로 저장되어 있습니다.

.idf 확장자는 여러 분야에서 쓰이지만, Jet DB + Paper/Factors 스키마 조합은 라벨 디자인 소프트웨어(특히 NiceLabel Designer의 레거시 IDF 포맷)와 일치합니다. iLabel2의 네이티브 포맷은 .idb / .lbl이며, 본 파일과는 다릅니다.

2.1 리스크 3종 심화 분석 (Kind·Type / 이미지 BLOB / DataSrc)

이전 보고서에서 「추가 샘플·역분석 필요」로 표시했던 항목을 access-parser 실데이터 파싱으로 재검증했습니다. 상세 JSON: test-idf-analysis.json · 추출 PNG: test-idf-extracted.png

A. Kind / Type 코드 (객체 종류)

바이너리 스캔에서 보였던 Kind는 객체 테이블이 아니라 Paper 컬럼입니다. 본 샘플에서는 Paper.Kind = null · 객체 구분은 Factors.Type + Factors.Attribute 조합으로 저장됩니다.

Factors.TypeAttributeCont / Image판정
1 0 리치텍스트 문자열 텍스트 — 폰트·스타일·색이 Cont 마커에 포함
2 8 (0b1000) Image PNG BLOB 이미지 — Cont 없음, 좌표는 Left/Top/Width/Height
3 7 (0b111) QR Code|…|payload QR/2D 바코드 — 종류는 Cont 첫 세그먼트 문자열

Cont 포맷 (확인된 2종):

텍스트: {#<dsIndex>,<fieldIndex>}{&<FontName>,<Size>,<style>,<ForeColor>}<plain text>
예시:   {#0,0}{&굴림,9,bius,-16777216}fdfdfsfdsfdsfdsfdsfdsfds  test

QR:     <Symbology>|<Key:Val;…>|<payload>
예시:   QR Code|QREncodeHint:0;QRErrorCorrectionLevel:3;QRVersion:0;FontName:Arial;FontSize:10;|qweee122233
  • {#0,0} — 데이터소스 슬롯 0 · 필드 0 참조(가변 데이터 연결 문법으로 추정). 본 파일은 Paper.DataSrc가 비어 있어 고정 텍스트 + 빈 바인딩 상태.
  • {&굴림,9,bius,-16777216} — 폰트명(UTF-8), 크기 9pt, 스타일 bius(Bold/Italic/Underline/Strike 플래그), BGR 색 -16777216(= 검정).
  • Attribute — 비트마스크 가능성( QR=7, Image=8 ). 1D Code128 등 다른 바코드·도형·선 Type 값은 추가 샘플 파일로 enum 확장 필요.

리스크 갱신: 중간 → 낮음~중간 — QR·텍스트·이미지 3종은 Type 매핑 확정. 미확인 Type(선/사각형/1D바코드/프린터 네이티브)만 샘플 수집 필요.

C. DataSrc / 변수·DB 연동

필드·위치본 샘플 값해석
Paper.DataSrc "" (빈 문자열) 라벨 전역 데이터소스 미설정
Factors.Cont 텍스트 접두 {#0,0} 객체 단위 DS#0 · 필드#0 바인딩 흔적 (내용은 고정 문자열)
스키마 메타 (UTF-16) DataSrc×4, Expression×3, Kind×4 컬럼·VBA 폼 정의 존재 — 값 레코드는 본 파일에 없음
별도 DB 테이블 없음 (Paper, Factors만 사용자 테이블) Excel/Access 연결 정보는 Forms·Connect·외부 .mdb일 가능성

Importer 1차 전략:

  • {#n,m} 마커 → Label-UP datasource.bindings[] placeholder (고정값 fallback).
  • Paper.DataSrc 비어 있으면 정적 라벨로 import · 경고만 표시.
  • Excel/DB 연결 IDF — NiceLabel에서 「DB 연결 + 가변 필드」 포함 샘플 1~2건 추가 수집 후 Forms/Connect 문자열·VBA 파싱.

리스크 갱신: 낮음 → 중간~낮음 — 문법 단서({#i,j}) 확보. 연결 문자열·Expression 실데이터는 가변 데이터 포함 샘플 필수.
