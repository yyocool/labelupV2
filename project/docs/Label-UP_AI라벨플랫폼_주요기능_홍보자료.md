# Label-UP AI 라벨 플랫폼
## 주요 기능 소개 (대외 홍보용)

**문서 용도:** 파트너·고객·언론·투자 미팅용 기능 요약  
**기준 자료:** 기능 구조 맵 · 경쟁 분석 · 서비스 정책 · 스토리보드(편집기·쇼핑몰)  
**작성 기준일:** 2026년 7월

---

## 1. 한 줄 소개

**Label-UP**은 AI로 라벨을 만들고, 규격에 맞춰 편집·출력하며, 용지 구매와 인쇄 의뢰까지 한 번에 이어지는 **AI 라벨 원스톱 플랫폼**입니다.

> *「예쁜 그림을 그리는 AI」가 아니라, 「라벨 업무 전체」를 돕는 Vertical AI*

---

## 2. 왜 Label-UP인가

| 기존 시장 | Label-UP |
|-----------|----------|
| 국내 라벨 3사: 무료 편집기 + 용지 판매 중심 | **디자인 → AI → 규격 → 출력 → 구매·의뢰**를 하나의 흐름으로 연결 |
| Canva 등 범용 AI: SNS·마케팅에 강함 | **라벨 규격·바코드·용지·인쇄**에 특화된 업무형 AI |
| 편집과 구매·인쇄가 분리된 UX | **클라우드 기반 원스톱**으로 재주문·LTV까지 설계 |

**지향점:** 누구나 만족스러운 라벨을 빠르게 만들고, 출력·제작까지 막힘 없이 이어지게 한다.

---

## 3. 플랫폼 한눈에 보기

```
[ AI 생성 / 템플릿 / 빈 캔버스 ]
              ↓
     [ 라벨 편집기 · 규격 · 데이터 ]
              ↓
     [ 미리보기 · PDF · 출력 ]
         ↙              ↘
 [ 용지·소모품 구매 ]  [ 인쇄 의뢰 · 맞춤 제작 ]
              ↓
     [ 주문 · 배송 · 마이페이지 · Pro 구독 ]
```

---

## 4. 핵심 가치 제안 (고객이 얻는 것)

1. **빠르게** — 대화·상품정보·엑셀만으로 AI 시안 생성, 바로 편집·출력  
2. **정확하게** — 폼텍·아이라벨·프린텍 등 국내 규격 검색·추천, 바코드·QR·데이터 연동  
3. **한곳에서** — 편집기에서 쇼핑몰·인쇄 의뢰까지 끊기지 않는 경험  
4. **성장에 맞춰** — Free / Pro 플랜, 포인트·쿠폰으로 사용량과 혜택 조절

## 5. 주요 기능

### 5.1 AI 라벨 (차별화 핵심)

| 기능 | 설명 | 고객 혜택 |
|------|------|-----------|
| **AI 디자인 생성** | 텍스트·상품정보·이미지·엑셀 기반 시안 생성 (일반/심플 모드) | 초안을 분 단위로 확보, 편집기에서 즉시 수정 |
| **AI 라벨 비서** | 규격 추천, 표시 가이드, 바코드·레이아웃·인쇄 전 체크 안내 | “어떻게 만들지?”를 대화로 해결 |
| **엑셀·파일 자동 라벨** | CSV·엑셀 컬럼 매핑 → 대량 라벨 일괄 생성 | 수백 SKU도 반복 작업 없이 처리 |
| **AI 다국어 라벨** | 수출·다국어 표기 지원 | 해외 납품·글로벌 SKU 대응 |
| **사용량·플랜 연동** | Free 한도 / Pro 월 할당, Backoffice 관리 | 비용·품질·한도를 투명하게 운영 |

### 5.2 라벨 편집기

| 영역 | 주요 기능 |
|------|-----------|
| **디자인 관리** | 새 디자인(빈 캔버스·AI·파일 가져오기), 내 디자인(작업중·저장·공유·즐겨찾기), 복제·이름 변경 |
| **편집 코어** | 상단바(저장·undo/redo·줌·미리보기·출력), 캔버스, 플로팅 툴바, 속성·레이어 패널 |
| **에셋·템플릿** | 배경·클립아트·아이콘·도형·표, 템플릿 갤러리, 외부 포맷·내 디자인 가져오기 |
| **객체·데이터** | 텍스트·이미지·도형·표, **바코드·QR**, 엑셀·CSV 데이터 연동·변수 매핑 |
| **규격** | 제조사·형태·용도·치수 검색, 여백 다이어그램, 용지 구매·편집 CTA |
| **출력** | 시트 미리보기, 라벨 복사(마스터/행·열/페이지), PDF·PNG·직접 출력 |
| **자료실** | 바코드 생성기, 디자인 자료, 폰트, 출력·재질·규격 가이드 |

### 5.3 쇼핑몰 · 제작 서비스

| 영역 | 주요 기능 |
|------|-----------|
| **카탈로그** | 라벨·스티커·태그·프린터·소모품, 검색·필터, 「라벨 편집하기」로 편집기 연결 |
| **구매** | 장바구니, 결제·쿠폰, 포인트 적립·사용 |
| **인쇄 의뢰** | 1장부터 인쇄 의뢰, 맞춤 견적·디자인 의뢰, 제작 진행현황 |
| **마이페이지** | 주문·배송, 결제·구독(Pro Plan), 내 정보·디자인 관리 |
| **운영(Backoffice)** | 상품·재고·주문, 디자인·규격·AI, 콘텐츠·통계·정산 |

### 5.4 계정 · 요금 · 정책

- **Free:** 기본 편집·템플릿·규격 검색, AI·저장 한도 적용  
- **Pro Plan:** AI·템플릿·할당량 확대, 고급 기능·우선 처리  
- 약관·개인정보·AI 이용·포인트·구독 정책을 서비스 화면에 일관 반영

## 6. 대표 이용 시나리오

### A. 소상공인 · 브랜드 담당자
1. 상품명·원재료를 입력해 **AI 시안 생성**  
2. 규격에 맞춰 편집 · 바코드 삽입  
3. PDF 출력 또는 **용지 구매 / 인쇄 의뢰**

### B. 물류·재고 담당자
1. 상품 마스터 **엑셀 업로드**  
2. 컬럼 매핑 → **대량 라벨 자동 생성**  
3. 시트 미리보기 후 출력·재주문

### C. 수출·다국어 라벨
1. 기본 국문 라벨 확정  
2. **AI 다국어**로 수출용 버전 생성  
3. 동일 규격으로 일괄 출력·의뢰

## 9. 대외 메시지 예시

**헤드라인 후보**
- AI로 만드는 라벨, 출력까지 한 번에 — Label-UP  
- 라벨 업무에 특화된 Vertical AI 플랫폼  
- 디자인부터 용지·인쇄 의뢰까지, 라벨의 모든 것  

**한 문단 소개 (보도·제안서용)**  
Label-UP은 생성형 AI와 국내 라벨 규격·바코드·데이터 연동을 결합한 클라우드 라벨 플랫폼입니다. 사용자는 AI로 시안을 만들고 편집기에서 다듬은 뒤, PDF 출력·용지 구매·인쇄 의뢰까지 같은 서비스에서 완료할 수 있습니다. 범용 디자인 툴과 달리 라벨 업무 맥락에 맞춘 Vertical AI로, 소상공인부터 물류·브랜드 담당자까지 생산성을 높입니다.
