# Label-UP — AI 라벨 플랫폼 주요 기능

> **대외 홍보용 요약**  
> 기준: Label-UP 기능 구조 맵 · 경쟁/요금 분석 · 구축 범위(1차·고도화)  
> 업데이트: 2026-07

---

## 한 줄 소개

**AI로 라벨을 만들고, 용지를 사고, 인쇄까지 한 곳에서.**  
Label-UP은 라벨·스티커 디자인부터 용지·소모품 구매, 인쇄 의뢰까지 이어지는 **원스톱 AI 라벨 플랫폼**입니다.

---

## 왜 Label-UP인가

| 기존 시장 | Label-UP |
|-----------|----------|
| 용지 판매 + 수동 편집 SW | **디자인 · 구매 · 인쇄**를 하나의 경험으로 연결 |
| 범용 디자인 툴의 「예쁜 이미지」 | **라벨 규격·바코드·시트 인쇄**에 맞춘 Vertical AI |
| 타사 포맷 고립 | 폼텍 등 **기존 작업물 가져오기**로 전환 부담 감소 |
| 무료 SW + 용지 마진만 | **AI·구독·커머스**가 결합된 플랫폼 LTV |

---

## 플랫폼 구성 (2축)

```
[ 라벨편집 ]  디자인 · AI · 데이터 · 출력
      ↕  규격·시안·장바구니로 연결
[ 쇼핑몰  ]  용지 · 소모품 · 인쇄의뢰 · 주문
```

## 1. 라벨 편집 — 만들고 · 다듬고 · 출력한다

### 1-1. 누구나 바로 시작하는 편집기
- **새 디자인**: 빈 캔버스 / AI 생성 / 외부 파일 가져오기
- **내 디자인**: 작업중 · 저장 · 공유 · 즐겨찾기, 이어서 편집·복제
- **캔버스 편집**: 텍스트·이미지·도형·표 · 드래그·리사이즈 · 레이어 관리
- **템플릿·에셋**: 배경 · 클립아트 · 아이콘 · 무료/프리미엄 템플릿 갤러리

### 1-2. 라벨 전용 핵심 기능
- **규격 검색**: 폼텍 · 아이라벨 · 프린텍 · 자사 규격 — 형태·용도·치수로 찾고 유사 규격 추천
- **바코드 · QR**: CODE128 / EAN13 / UPC / CODE39 · QR(URL·전화·Wi-Fi)
- **데이터 연동**: 엑셀·CSV 업로드 → 변수 매핑 → 대량 라벨 생성
- **라벨복사**: 한 장 디자인을 행·열·페이지·시트 전체에 복제 (마스터 동기화)
- **인쇄 미리보기**: 실제 시트 배치·수량·여백을 확인한 뒤 PDF/직접 출력

### 1-3. 타사 포맷 가져오기
- **폼텍(Formtec)** Design Pro 파일(`.dgz` / `.dgf`) 분석·객체 반영
- **아이라벨** 데이터(`.lbl` / `.xml` 등) 반입 · 변수 매핑
- **애니라벨** 호환 규격·SKU 매핑으로 기존 업무 연속성 지원  
→ *「쓰던 파일을 버리고 다시 그리는」 비용을 줄입니다.*

## 2. 라벨 GPT — AI가 라벨 업무를 대신한다

> Canva가 「예쁜 그림」을, 국내 라벨 SW가 「수동 편집」을 한다면  
> **라벨 GPT는 「라벨 업무 전체」를 AI가 돕습니다.**

| 기능 | 한 줄 가치 |
|------|------------|
| **AI 디자인 생성** | 짧은 지시문·상품명·이미지로 시안 후보 생성 → 편집기에서 바로 수정 |
| **AI 라벨 비서** | 규격 추천 · 표시 가이드 · 바코드·레이아웃 조언 · 인쇄 전 체크리스트 |
| **엑셀·파일 자동 라벨** | CSV/엑셀 → 일괄 라벨 생성 (대량·반복 업무 자동화) |
| **사진 → 라벨** | 제품 사진 한 장으로 초안 완성 |
| **AI OCR** | 기존 라벨 스캔 → 편집·재인쇄 |
| **AI 다국어** | 수출·현지화 라벨 번역·재배치 |

**요금 메시지 (요약)**  
- Free: AI 체험 · 기본 편집 · 용지 구매  
- Pro: AI 할당 · 프리미엄 템플릿 · 일괄·다국어 등 업무용 AI 풀세트

## 3. 쇼핑몰 — 사고 · 의뢰하고 · 다시 주문한다

### 3-1. 라벨 전문 카탈로그
- A4 · 롤 · 감열 · 열전사 라벨지
- 투명 · 방수 · 유포지 · 아트지 스티커
- 태그 · 라벨 프린터 · 리본/잉크/토너 · 번들 상품

### 3-2. 구매 · 결제 · 리워드
- 검색·필터(재질·형태·용도·가격) · 장바구니 · PG 결제
- **포인트**(1P ≈ 1원) · 쿠폰 · Free / Pro 구독
- 주문·배송 추적 · 마이페이지에서 최근 디자인 바로 편집

### 3-3. 인쇄 의뢰 · 맞춤 제작
- PDF / AI / PSD 업로드 후 디지털·옵셋 인쇄 의뢰
- 특수 규격·대량·맞춤 디자인 **견적·시안 승인**
- 접수 → 시안 → 제작 → 출고 **진행 현황** 한눈에

### 3-4. 편집 ↔ 쇼핑 연결 (원스톱)
| 편집기에서 | 쇼핑몰에서 |
|------------|------------|
| 「용지 구매」 → 동일 규격 상품 | 「라벨 편집하기」 → 규격 프리셋 편집기 |
| 「출력」 → 장바구니·인쇄 의뢰 | 주문 내역에서 재주문·재편집 |

## 5. 고객이 체감하는 여정

```
① 규격 찾기 / AI로 시안 만들기
        ↓
② 편집기에서 다듬기 (템플릿·바코드·데이터)
        ↓
③ 시트 미리보기 · PDF·출력
        ↓
④ 같은 규격 용지 구매 또는 인쇄 의뢰
        ↓
⑤ 주문·배송 · 다음엔 AI·템플릿으로 더 빠르게
```
